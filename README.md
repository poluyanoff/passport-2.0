# Passport 2.0

Прототип формы «Постановка задачи на дизайн»: последовательный гайд, в котором продуктолог собирает паспорт дизайн-задачи и получает статус готовности к передаче.

## Стек

- Angular 19
- Taiga UI 4.x (T-Банк дизайн-система)
- LESS
- Dialkit — панель разработчика для быстрого перехода между шагами (только в dev-режиме)

## Запуск

```bash
npm install
ng serve
```

Приложение откроется на `http://localhost:4200/`.

Для dev-сервера на конкретном порту:

```bash
ng serve --host 127.0.0.1 --port 5196
```

## Сборка

```bash
ng build
```

Собранные файлы попадают в `dist/passport-form/browser`.

Если продакшен-сборка падает на бюджете бандла, можно собрать development-версию:

```bash
ng build --configuration development
```

## Как устроен проект

- `src/app/steps.data.ts` — шаги, источники, референсы, варианты долей аудитории.
- `src/app/app.component.ts` — логика валидации, статусов и переходов между шагами.
- `src/app/app.component.html` — разметка шагов формы.
- `src/app/app.component.less` — стили формы и анимации переходов.
- `src/app/dev-nav.ts` — dialkit-панель разработчика.
- `legacy/passport-2.0-standalone.html` — старая одностраничная версия формы без Angular.
