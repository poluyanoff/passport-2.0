# Разработка и проверки

## Что менять чаще всего

### Шаги

Добавить или переставить шаг — править `steps.data.ts` и соответствующий `@if (step.id === ...)` блок в `app.component.html`.

### Тексты полей

Заголовки шагов и подзаголовки — в `steps.data.ts`. Плейсхолдеры полей — в `app.component.html`.

### Проверка статусов

Цвет шага и итоговая готовность считаются в `state()`, `readiness()` и `rules()` внутри `app.component.ts`.

## Локальная проверка

```bash
ng serve --host 127.0.0.1 --port 5196
```

В dev-режиме в углу работает dialkit-панель: можно быстро прыгать между шагами без валидации.

## Сборка

```bash
ng build --configuration development
```

Продакшен-сборка может упереться в бюджет бандла из-за полного набора Taiga UI. Если это блокирует задачу, поднять бюджет в `angular.json` или уменьшить импорт компонентов.
