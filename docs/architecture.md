# Архитектура

Прототип собран на Angular (standalone-компоненты) с дизайн-системой Taiga UI.

## Поток данных

`app.component.ts` держит модель формы в `AbstractControl`-less виде: обычный объект `s`, создаваемый функцией `empty()`. Для реактивности шагов и текущей позиции используются Angular signals.

## Шаги

Список шагов задаётся в `steps.data.ts` как `STEPS`. Блоки формы отрисовываются в `app.component.html` через `@if (step.id === ...)`.

Текущий порядок:

1. `problem` — аудитория, проблема и текущее решение.
2. `src` — чем подтверждается проблема.
3. `business` — что теряет бизнес.
4. `hyp` — гипотеза и метрики.
5. `refs` — что уже сделано другими (необязательный).
6. `why` — сроки.

## Валидация и статус передачи

В `app.component.ts`:

- `validation()` — блокер перехода на следующий шаг.
- `state()` — цвет шага: зелёный, жёлтый или красный.
- `readiness()` — итоговая готовность паспорта: «Не готово», «Можно передавать с рисками», «Готово».
- `OPTIONAL` — список id необязательных шагов; сейчас это `refs`.

## Dev-панель

В `isDevMode()` подключается `dev-nav.ts`: в углу появляется dialkit-панель с кнопками перехода по шагам. В собраный продакшен-бандл она не попадает.

## Сборка и ассеты

Иконки Taiga UI лежат в `public/assets/taiga-ui/icons`. Путь задаётся через `tuiAssetsPathProvider('assets/taiga-ui/icons')` в `app.config.ts`, потому что дефолтный CDN-путь Т-Банка отдаёт 403.
